# TradingBot "Kron" — AI-Powered MT5 Trading Bot

Торговый бот для MetaTrader 5 с тройным AI-анализом рынка: технические индикаторы + нейросеть Kronos + Gemini LLM.

---

## Как это работает (простое объяснение)

### Общая идея

Представь что у тебя есть три аналитика, которые смотрят на рынок одновременно:

1. **Технический аналитик** — считает RSI, MACD, Боллинджер, ATR и ещё 6+ индикаторов, голосует: BUY или SELL
2. **Нейросеть Kronos** — анализирует паттерны K-линий (свечей), смотрит на импульс за 5/10/20 свечей, объёмные всплески, пин-бары
3. **Gemini AI (LLM)** — получает данные как промпт и даёт своё мнение на основе текста

Каждый высказывается с **уверенностью (confidence 0–100%)**.  
Бот взвешивает голоса: **50% техника + 25% Kronos + 25% Gemini**.  
Если итоговая уверенность **выше 65%** → сделка открывается.  
Если ниже — HOLD, ждём следующего цикла.

---

## Жизненный цикл одного цикла (раз в 15 минут)

```
1. Подключиться к MT5 терминалу
2. Скачать последние 300 свечей XAUUSD H1
3. Рассчитать технические индикаторы
4. Запустить Kronos — K-line нейросеть
5. Спросить Gemini — LLM анализ
6. Взвесить все три голоса
   └─ confidence >= 65% → открыть ордер (лот = 1% депозита / SL)
   └─ confidence < 65%  → HOLD, ждать
7. Сохранить сигнал и снимок портфеля в БД
8. Отправить уведомление в Telegram (если бот включён)
9. Спать 15 минут, повторить
```

## Запуск

### Требования
- Windows (MetaTrader 5 работает только на Windows)
- MetaTrader 5 терминал должен быть **открыт** перед запуском бота
- Python 3.10+

### Установка зависимостей
```bash
git submodule update --init --recursive
pip install -r requirements.txt
```

### Модель Kronos

Используется официальный checkpoint `NeoQuasar/Kronos-base` и соответствующий
`NeoQuasar/Kronos-Tokenizer-base`. При первом анализе Hugging Face скачает их
в локальный кэш пользователя; повторно загружать веса при каждом цикле не нужно.
Исходный код Kronos подключён как submodule в `vendor/Kronos`.

Предиктор автоматически выбирает CUDA, если установленная сборка PyTorch её
поддерживает; иначе работает на CPU. Для использования видеокарты нужна CUDA-сборка
PyTorch — установите её командой для Windows из
[официального селектора PyTorch](https://pytorch.org/get-started/locally/).
Проверить доступность CUDA можно командой:

```bash
python -c "import torch; print(torch.cuda.is_available())"
```

### Запуск

```bash
# Торговля на демо-счете AMarkets Demo #7872510
python main.py --demo

# Демо + Telegram бот
python main.py --demo --bot

# Paper simulation без заявок в MT5
python main.py --simulate

# Реал (XM #401397663) — ОСТОРОЖНО, реальные деньги!
python main.py --real

# Быстрый анализ символа без торговли
python main.py --analyze XAUUSD
python main.py --analyze EURUSD

# Торговать конкретным символом
python main.py --demo -s EURUSD

# Торговать несколькими символами последовательно в каждом цикле
python main.py --demo -s BTCUSD,XAUUSD
```

Символы можно разделять запятыми с пробелами: `BTCUSD, XAUUSD, EURUSD`.
Для каждого символа отдельно загружаются свечи, рассчитываются индикаторы,
вызывается Kronos и сохраняется сигнал. Лимит ордеров в минуту общий для всего
аккаунта, поэтому добавление символов может привести к более быстрому достижению
`MAX_ORDERS_PER_MIN`.

Kronos в текущей реализации не дообучается онлайн и не изменяет свои веса.
Он использует отдельные данные каждого символа и выполняет walk-forward
калибровку confidence по истории этого же символа. Это безопаснее, чем смешивать
рынки; настоящее дообучение весов потребовало бы отдельного датасета, целевой
функции и контроля переобучения.
```env
# Реальный счёт XM
MT5_LOGIN=401397663
MT5_PASSWORD=YourPassword

# Демо AMarkets (используется при --demo)

# AI

# Database (опционально, бот работает и без неё)

```

## Риск-менеджмент

- **Размер лота** = 1% от депозита, делённый на размер Stop Loss в пипсах
- **Stop Loss** = 50 пипсов (настраивается в .env: `DEFAULT_SL_PIPS`)
- **Take Profit** = 100 пипсов (настраивается: `DEFAULT_TP_PIPS`)
- **Макс. открытых позиций** = 3
- **Лимит ордеров** = не более 3 за минуту (защита от перегрева)
- **Порог входа** = уверенность AI >= 65% (настраивается: `CONFIDENCE_THRESHOLD`)

## AI — как считается сигнал

### Технические индикаторы (вес 50%)
10-факторное взвешенное голосование:
- RSI: перекупленность/перепроданность
- MACD: крест сигнальной линии
- Bollinger Bands: выход за полосы
- Stochastic: перекупленность/перепроданность
- EMA: расположение цены относительно EMA-12/26
- SMA: Golden/Death Cross (SMA-50 vs SMA-200)
- ATR: нормализованная волатильность
- Volume: всплески относительно скользящего среднего

### Kronos (вес 25%)
Нейросеть для паттернов K-линий:
- Многомасштабный импульс за 5, 10, 20 свечей
- Анализ теней свечей (пин-бары, молоты, звёзды)
- Объёмные всплески (z-score нормализация)
- Динамический SL/TP через ATR

### Gemini LLM (вес 25%)
Передаёт последние 20 свечей и все индикаторы в промпт.  
Gemini отвечает JSON: `{"signal": "BUY", "confidence": 0.72, "reason": "..."}`.  
Используется модель `gemini-2.5-flash`.

### Итоговое решение
```
score = tech_score * 0.50 + kronos_score * 0.25 + gemini_score * 0.25
if score > threshold:  → BUY
if score < -threshold: → SELL
else:                  → HOLD (ждём)
```

## База данных (PostgreSQL, опционально)

Бот **работает без БД** — если PostgreSQL недоступна, данные просто не пишутся, ошибок нет.

Если БД есть — хранит:
- **Candle** — все загруженные свечи (300 штук каждый цикл, upsert)
- **Signal** — каждый AI-сигнал с уверенностью и причиной
- **Trade** — каждый открытый ордер
- **PortfolioSnapshot** — снимок баланса каждый цикл

Запуск PostgreSQL через Docker:
```bash
docker-compose up -d
```
