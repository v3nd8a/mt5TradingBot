# Инструкции по экономии токенов

У тебя подгружены MCP-серверы для работы с графом кода (`repo-graph` и `code-graph`).

СТРОГИЕ ПРАВИЛА НАВИГАЦИИ:
1. НЕ читай файлы целиком и НЕ используй `grep`/`find` для поиска функций и классов.
2. Для анализа структуры используй MCP-инструменты графа (`trace`, `impact`, `get_call_graph`).
3. Считывай содержимое файла через `read_file` ТОЛЬКО тогда, когда из графа получен точный путь и номер строки.
